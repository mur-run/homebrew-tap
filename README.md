# Homebrew Tap for MUR

Official Homebrew formulae for [MUR](https://github.com/mur-run/mur) tools.

## Available Formulae

| Formula | Description |
|---------|-------------|
| `mur` | Invisible continuous learning system for AI coding assistants |
| `mur-commander` | Autonomous workflow execution agent with multi-model AI orchestration |

## Installation

```bash
brew tap mur-run/tap

# Install mur (learning system)
brew install mur

# Install mur-commander (workflow agent)
brew install mur-commander
```

## Upgrade

```bash
brew upgrade mur
brew upgrade mur-commander
```

## Uninstall

```bash
brew uninstall mur mur-commander
brew untap mur-run/tap
```
